## Come compilare ed eseguire

Con Code::Blocks: apri il file `.c` con *File → Open* e premi **F9**.

Da terminale, con GCC:

```
gcc nome-esercizio.c -o nome-esercizio
./nome-esercizio
```

## Note

Ogni file inizia con un commento che riporta il testo dell'esercizio.
