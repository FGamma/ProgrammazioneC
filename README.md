# Programmazione C

Raccolta di esercizi in linguaggio C, organizzati per argomento.
Ogni cartella contiene un gruppo di esercizi, ognuno in un file `.c` indipendente con il proprio `main()`.

## Argomenti

- `01-basi`
- `02-cicli`: for, while, do-while
- `03-vettori`: vettori e matrici
- `04-stringhe`: manipolazione di stringhe
- `05-matrici`: funzioni e passaggio dei parametri
- `06-funzioni`: puntatori e memoria dinamica
- `07-file`: lettura e scrittura di file

## Come compilare ed eseguire

Con Code::Blocks: apri il file `.c` con *File → Open* e premi **F9**.

Da terminale, con GCC:

```
gcc nome-esercizio.c -o nome-esercizio
./nome-esercizio
```

## Note

Ogni file inizia con un commento che riporta il testo dell'esercizio.
